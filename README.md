# Mini-SIRH Backend

Spring Boot backend for a Mini Human Resources Management System.

## Features
- Authentication
- Role-based security
- Collaborator management
- Department management
- Training management
- Leave management
- IoT attendance simulation
- Dashboard statistics
- Swagger API documentation

## Tech Stack
- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- MySQL
- Lombok
- Swagger/OpenAPI
- Python RFID simulation
